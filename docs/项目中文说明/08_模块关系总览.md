# 模块关系总览

## 1. 主链关系

当前项目主链：

```text
Simulation -> Core -> Perception / MARL / NavDP / Locomotion -> Dashboard
```

其中最核心的控制闭环是：

```text
Simulation -> Core -> NavDP -> Locomotion -> Simulation
```

---

## 2. 各模块在系统中的位置

### Simulation

- 提供物理世界
- 提供传感器
- 执行控制命令

### Core

- 汇总状态
- 调用外部模块
- 组合控制逻辑
- 提供 dashboard

### Perception

- 从 `Core` 打包输入中做感知估计

### MARL

- 输出双狗协同子目标
- 提供角色分配

### NavDP

- 把子目标转成路径

### Locomotion

- 把路径与速度命令转成低层关节动作

### ROS2

- 提供 launch / bringup / 工作区编排

---

## 3. 当前控制权分布

### 高层

- `MARL` 决定协同子目标

### 中层

- `NavDP` 决定 waypoint 路径

### 低层

- `Locomotion` 决定低层 joint action

### 近距离收口

- 当前主要由 `Core` 接管

---

## 4. 当前最值得记住的事实

1. `legacy` 是主推荐 simulation 运行线。
2. `Core` 当前已经不只是转发层，而是有明确接管逻辑的主控层。
3. `MARL` 已经是正式服务，而不是单纯研究代码。
4. `Dashboard` 已经承担较强的联调与诊断职责。

---

## 5. 一句话概括

这个项目现在不是“几个模型并排放着”，而是一条已经成型的多模块协同控制系统。
